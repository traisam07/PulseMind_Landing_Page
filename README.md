# PulseMind website — review draft

One-page React + Vite + Tailwind draft built from the *PulseMind Website — Content Sheet*. It shows real copy in place for review; visual design comes later.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```

## Where things live

| What | Where |
| --- | --- |
| All page text, alt text, aria labels, links, asset paths | `src/content/en.json` (one object per section) |
| Vietnamese copy | `src/content/vi.json`, generated by `npm run make-vi` (prefixes every string with `[VI] `). Replace with the real translation when ready. URLs, file paths and email subjects are not prefixed. |
| Sections, in page order | `src/sections/` |
| Shared pieces (header, footer, placeholder text, image slots) | `src/components/` |
| Brand colours | `@theme` block in `src/index.css` |
| Page title and description meta tags | Injected into `index.html` from `en.json` at build time (`vite.config.js`) |

## Placeholders

- Every missing value is written in `[BRACKETS]` in `en.json`. Search that file for `[` to find them all. (Email subjects such as `[Partnership] PulseMind` also contain brackets; those are final.)
- Bracketed text renders with a yellow, dashed, monospace highlight.
- A link whose URL is a placeholder (`links.demo`, `links.facebook`, `links.instagram`) points to `#` and carries `data-placeholder`. Put the real URL in `links` and it opens in a new tab.

## Assets

Drop files into `public/assets/` using the paths in `en.json`. Until a file exists, a grey labelled box shows in its place.

```
public/assets/wordmark-dark.svg       header
public/assets/wordmark-light.svg      footer
public/assets/brandmark.svg           favicon + Approach diagram (crimson recolour)
public/assets/lungs.png               Home
public/assets/icons/ventilator.svg, bedside-monitor.svg, lab-results.svg, clinical-record.svg
public/assets/screenshots/overview.png, patient-detail.png, parameter-detail.png
public/assets/photos/team-group.jpg, team-working.jpg, bk-innovation.jpg, vnu-rnd.jpg
```

Headshots, optional milestone photos and photo-strip images have empty `src` values. Add a path in `en.json` when a photo is ready.

## Toggles

- `demo.showDeviceNote`: set to `false` if the demo works well on phones.
